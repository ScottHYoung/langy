## Archived Features

This directory preserves experimental flows that have been temporarily removed from the live app:

- `read_listen_mode/` contains the previous multi-mode UI and session state that offered separate read, listen, and blended study experiences.
- `actr_demo/` stores the ACT-R powered half-life demo code, including the companion model utilities.

These snapshots are kept for future reference if we decide to revive or revisit the features.
